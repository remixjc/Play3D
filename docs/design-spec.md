# 《折光》设计规范

首屏要让玩家一眼认出挡板、小球和砖阵，确认怎样开球。使用同一套内容比较了两种布局草图。

```text
并排  [ 折光 / 开始游戏 / 最高分 ]  [ 分数 / 关卡 / 生命        ]
                                      [       立体球场          ]
居中  [       折光 / 分数 / 关卡 / 生命                         ]
      [                  立体球场                               ]
      [                开始游戏 / 最高分                        ]
```

桌面选择并排布局。标题、开球和最高分在左，右侧球场从开局就完整可见。移动端将标题、球场和操作按纵向排列，开球和暂停都有可直接触碰的按钮。

- 球场使用 WebGL 透视镜头、带倒角的实体砖块、网格底板和两侧灯带。亮白球与青绿色挡板在暗背景中保持可辨。多层砖阵使用柑橘、紫罗兰、青蓝和荧绿，受击时用碎片和光圈提示碰撞位置。
- 页面背景 `--page` 为 `#0b0e16`，面板 `--panel` 为 `#111621`，主操作 `--accent` 为`#c4fa73`，次要文字 `--muted` 为 `#9aa6bc`。分数以高亮数字呈现，剩余生命同时使用图形和数字。
- 英文游戏名使用本地 Barlow Condensed，状态数字使用本地 Space Mono，中文沿用设备系统字体。桌面外框宽度上限 1384px，左右栏间距 32px。移动端外边距 16px，主触控按钮至少 44px 高。
- 菜单、待发球、对局、暂停、关卡结束与全局结束使用同一个球场。键盘鼠标与触屏共享状态。减少动态效果的系统设置会降低闪光、球轨和碎片数量，保留碰撞反馈。
- 自动发球倒计时显示在球场中央，使用大号 Space Mono 数字与荧绿细环。挡板和瞄准线保持可见。暂停时隐藏数字并保存剩余时间，继续后接着倒数。
- 设置使用现有暗色对话框。积分余额和领取入口在顶部，三种道具按照名称、效果、数量和价格排列。兑换按钮最小高度 44px，库存、余额不足与已领取都有文字状态。在窄屏保留单列道具列表并允许对话框内部滚动。
- 道具快捷栏放在最高分下方，窄屏占一整行。按钮同时显示名称、库存或效果剩余时间，键盘使用 1、2、3。宽幅以挡板变宽提示，缓速以紫色球光提示，护球在球场底边显示一道金色防线。
